Code review — 2026-10-31

Reviewed FITS parsing/writing/tables, XISF resources/codecs/references, image statistics/layouts/rendering, astronomy metadata/WCS, tests and packaging. Three parallel reviews were followed by independent cross-review of the patches. This is a source and regression review, not a formal security audit or proof of universal interoperability.

Requested regression tests

XisfMalformedInputRegressionTests protects both original malformed-input fixes:

  • Non-seekable input with a complete preamble but truncated XML produces XisfFormatException with an inner EndOfStreamException. Sync and async entry points leave the caller stream open.
  • Invalid Base64/hex characters and incomplete groups produce XisfFormatException with an inner FormatException at lazy access. Inline/embedded storage and repeat access after failure are covered.
  • Ordinary storage IOException remains unchanged. Corrupt zlib now also retains its codec exception as the cause of a format error, for stream and path access.

Findings fixed

Priority describes the discovered consequence, not an outstanding blocker.

Priority Defect and correction Regression tests
P1 Recursive XISF references could exhaust the process stack. Iterative traversal preserves cycle detection and accepts 20,000-node shallow chains. XisfReferenceRegressionTests
P1 Huge shuffle item sizes caused billions of empty iterations on tiny blocks. Return the owned tail immediately when there is no complete item. XisfResourceRegressionTests
P1 XISF block limits were checked after allocating concatenated/decoded text or reading an external file. Preflight text nodes and opened-file length; also reject rooted cross-volume header-relative escapes. XisfResourceRegressionTests
P1 Repeated FITS descriptors could amplify a small heap into huge decoded arrays. Debit a cumulative per-table element budget before allocating. FitsTableRegressionTests
P1 Unsupported WCS projections/axes/distortions silently returned incorrect celestial coordinates. Reject unsupported explicit transforms; respect sparse CD defaults and CD precedence. WorldCoordinateRegressionTests
P2 Empty FITS numeric/P/Q arrays divided by zero or read missing descriptors. Return typed empty values and reject invalid repeated descriptors. FitsTableRegressionTests
P2 ASCII integers lost precision above 2^53, E vectors lost their float array type, and ASCII null markers failed parsing. Preserve Int64 values and types; recognize null text before conversion. FitsTableRegressionTests
P2 FITS long strings split escaped apostrophes and dropped continuation comments. Split logical characters and preserve final comments. Reject unrepresentable ASCII/card content instead of silently replacing/truncating it. FitsLongStringRegressionTests
P2 Distributed XISF paths assumed case-insensitive directories and rewrote legal Unix backslash filenames. Centralize platform-aware checks and preserve filenames. XisfWriterPathRegressionTests
P2 Finite extremes overflowed median, histogram placement, mean, normalization or variance. Retain ordinary arithmetic with scaled fallbacks; use wide statistics sampling arithmetic. ImageStatisticsRegressionTests, ParsedNormalizationRegressionTests
P2 XISF-carried FITS strings leaked quotes and prevented timestamp extraction. Decode once while native FITS strings retain their literal values. AstronomyMetadataRegressionTests
Performance Invalid image requests decoded entire lazy images before failing. Run shared cheap validators before source access. ImageStatisticsRegressionTests
Performance Statistics sorted twice and allocated a second sampled buffer. Exact selection reuses owned samples for MAD; extrema are retained before reordering. Independent sorted-reference statistics tests

Readability and compatibility

  • CelestialWorldCoordinateSystem now has its own file. A small internal helper shares FITS string decoding. Validation and distributed-path checks are centralized.
  • Comments explain numeric slow paths, buffer ownership and iterative reference traversal. The existing exact-selection fallback and SIMD helpers are retained.
  • The benchmark links the production selection source without widening public APIs.
  • New FitsReaderOptions.MaximumTableElements defaults to 10,000,000 per table. Strings count characters, bit fields count bits, repeated heap references count each decoded element again. Raise it explicitly for larger trusted tables.
  • Unscaled ASCII I cells now return long; scaled cells retain physical double values. Callers assuming all ASCII numbers were double must handle both types.
  • FITS metadata that cannot fit printable ASCII/80-character cards throws rather than losing content. Failed single-file path writes preserve existing output.
  • The WCS convenience API supports degree-based RA/DEC TAN in that axis order, plus its original linear mode when both CTYPE keywords are absent. Unsupported explicit conventions, pole overrides and distortion parameters are rejected. This does not change the separate native XISF astrometric evaluator.

Remaining findings and profiling targets

  1. P2 — optional network body timeout: XISF applies NetworkTimeout to request and stream acquisition, but synchronous body copying does not observe cancellation. A server stalling after headers may outlive that timeout. Network access is disabled by default. Follow-up: cancellation-aware HTTP body reads plus a local stalling-server test. Arbitrary custom streams may require their own cancellation cooperation.
  2. Unmeasured performance opportunity: FITS numeric table decoding boxes elements and creates intermediate lists/arrays, including scalar cells. Benchmark real scalar/vector tables with scaling/nulls before adding specialized typed decoders.
  3. Unmeasured performance opportunity: rectangular-array image factories flatten then copy, matrix-property decoding boxes elements, and matching-type channel/region reads still have per-sample paths. Profile allocation and row-copy costs before changing ownership/layout contracts.
  4. Unmeasured performance opportunity: Lab rendering looks up working-space matrices per pixel. Benchmark an immutable per-render transform and define how caller mutation of working-space collections is handled before changing it.

The network timeout is a known limitation, not a tested guarantee. The review does not claim universal maximum performance or absence of further defects.

Validation includes the full Release suite, locked restore, package generation, and the local 11-file FITS corpus. Photographs/reports remain outside tracked source.
