Versioning and releases

AstroView uses Semantic Versioning. The next release version is defined once in eng/Versions.props; Phase 2 development targets 0.3.0 after the published 0.2.0 release. While the major version is zero, minor releases can include documented API changes. Patch releases are reserved for compatible corrections. Record changes in CHANGELOG.md.

Build Package version
Local/default 0.3.0-dev
CI push or pull request 0.3.0-ci.<run-number>.<attempt>
Tag v0.3.0-rc.1 0.3.0-rc.1
Tag v0.3.0 0.3.0

Assembly/file versions use the numeric release prefix (0.3.0.0). Informational versions retain the package version and SDK-provided Git commit metadata for traceability. A tag must match the configured version; CI rejects mismatches and invalid prerelease identifiers. Build metadata belongs in the informational version, not the release tag. CI reruns receive distinct prerelease package versions.

Building a version explicitly

dotnet build AstroView.sln -c Release -p:Version=0.3.0-rc.1
dotnet test AstroView.sln -c Release --no-build
dotnet pack src/AstroView.Core/AstroView.Core.csproj -c Release --no-build -p:Version=0.3.0-rc.1 -o artifacts/packages

Build and pack must use the same version. CI resolves it once with eng/Get-BuildVersion.ps1 and reuses it throughout the workflow. Run eng/Test-BuildVersion.ps1 in PowerShell to check the policy.

Release checklist

  1. Update eng/Versions.props and the changelog; review intentional API changes.
  2. Restore locked dependencies; build, test, and pack on supported CI platforms.
  3. Verify the package version, assembly version, informational commit metadata, dependency list, README, and attribution files.
  4. Create and push the matching v<version> tag when a release is authorized. The release workflow validates, tests and publishes a GitHub Release with separate desktop and Core archives. It does not publish to NuGet.
  5. Advance the prefix for subsequent development; do not move an already published tag.

No release tag or public package is created merely by changing this version file.
