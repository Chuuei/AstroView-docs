AstroView.Core developer guide

AstroView.Core is a .NET 10 library for astronomical image files. It contains FITS and XISF readers and writers, native document models, typed metadata and tables, scientific sample access, display rendering, statistics, conversion, validation and supported astrometric transforms. All public APIs use the AstroView.Core namespace, including types stored in the Fits, Xisf, Imaging and Astronomy source directories.

The library is independent of Avalonia and the AstroView desktop application. Compression and XML cryptography have managed package dependencies, distributed with the Core release or restored through NuGet. No XISFLib package is required.

Integration principles

  1. Decide whether you need document preservation, editable content or a cross-format conversion. They have different fidelity contracts.
  2. Keep file sources available while a parsed XISF document can still read lazy blocks. Loading its XML does not materialize every image or ancillary block.
  3. Use a sample type that preserves the values you need. A double array is convenient for analysis but cannot represent every 64-bit integer.
  4. Configure budgets and external-resource policy before accepting arbitrary files. Reuse a deliberate policy across reads rather than raising limits in response to each failure.
  5. Treat preview pixels, scientific samples, file digests, semantic validation and signer trust as separate concepts in your application.

Version and support contract

The examples target .NET 10 and the current 0.2.0 development API. Local builds have a -dev suffix; CI and tagged versions follow the versioning policy. A project targeting an older framework cannot reference the current library without being retargeted.

Windows, Linux and macOS are exercised by CI. The support matrix distinguishes reading, writing, preservation and semantic evaluation for individual format features. Use that matrix when designing an import contract; the existence of an XML object or FITS card is not evidence that every associated convention is evaluated.
