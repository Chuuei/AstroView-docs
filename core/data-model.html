Use XisfWriter.Write(path, parsedDocument) for document-preserving output. Use ToEditable() and the editable writer overload when you want to materialize content and choose new storage settings. The two overload families have different preservation behavior; see XISF.

Dimensions and channels

Dimensions are expressed as [width, height, further axes…]. Channel count is separate in the XISF model. The number of scalar samples is the product of the dimensions multiplied by the channel count; complex samples have two real components each. Validate products with checked arithmetic when allocating.

FromArray(T[,]) follows CLR array indexing [height, width]. FromArray(T[,,]) follows [height, width, channel]. Do not copy the shape of a CLR array directly into the width-first dimensions argument.

FITS axes describe scientific dimensions. A third axis of length three might be three wavelength planes rather than RGB. Conversion defaults to preserving dimensions; use FitsAxisInterpretation.RgbOrRgba only when that interpretation is appropriate for the data.

Layout and endianness

For two RGB pixels, planar sample order is R0 R1 G0 G1 B0 B1; interleaved order is R0 G0 B0 R1 G1 B1. Parsed and editable typed reads default to planar output even when the original file stores interleaved samples. Request the desired layout explicitly at application boundaries.

ReadRawData() returns stored sample bytes after decompression and unshuffling. Those bytes still have the image's declared byte order and sample layout. IsBigEndian and PixelStorage describe how to interpret them. Typed methods perform byte-order handling for you. FITS raw image samples use FITS storage conventions; physical values additionally apply BSCALE, BZERO and BLANK.

Numeric precision

XISF image formats include UInt8, UInt16, UInt32, UInt64, Float32, Float64, Complex32 and Complex64. Property/table types include additional signed, vector, matrix and opaque representations; image and property type sets are not interchangeable.

Every integer up to 2^53 is exactly representable in binary64; above that, some integers are not. Do not route UInt64 through double before formatting or serializing it. The exact-integer recipe demonstrates a typed FITS-to-XISF path for unsigned storage conventions.

Ownership and concurrency

Caller-provided streams remain open. XISF stream loads buffer input within the configured budget; path loads retain source information and may reopen files. Keep the original file and any referenced XISB files available and unchanged. Moving a header without its blocks can make a previously parsed document fail on a later pixel or metadata read.

Parsed XML and exposed array values generally use detached copies. Modifying document.Xml alone does not update the document: use EditXml and retain its returned document. Typed sample arrays are new arrays. Editable metadata and table collections are mutable and are not a thread-safe shared editing model.

Await asynchronous operations before mutating their inputs or releasing their sources. Async wrappers snapshot options, but that does not turn the entire editable object graph into an immutable snapshot. See resource policy and performance for memory and cancellation boundaries.
