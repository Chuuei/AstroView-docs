AstroView

Executable recipes

The examples in this guide come from one compiled C# program. Documentation CI checks that displayed snippets match that program, builds it against the current Core project and runs its round-trip checks on Windows, Linux and macOS.

Run

From the repository root with the .NET 10 SDK:

dotnet restore AstroView.sln --locked-mode
dotnet run --project examples/AstroView.Core.Examples -c Release -- artifacts/my-examples

Use a dedicated writable directory. The program generates small artificial images; no external corpus, network access or GUI is required. It prints a success message only after every recipe completes.

The source is in examples/AstroView.Core.Examples. All recipes use the same output directory; later recipes intentionally reopen files created earlier. They check expected values with normal C# exceptions, so they can also serve as a simple integration smoke test.

These examples verify AstroView's own operations. For independently produced files and reference-reader comparisons, use the separate interoperability suite.
