FITS/XISF support matrix

Baseline updated against the source, regression tests and independent fixtures on 2026-11-01. This is an implementation contract and gap inventory, not certification of full FITS 4.0 or XISF Revision 1 conformance. Update the matrix with each release and link new independent interoperability evidence as it becomes available.

How to read the matrix

  • Yes: the documented API implements the capability for the stated scope.
  • Partial: a restriction or preservation condition in the notes matters.
  • No: the capability is not implemented as a supported high-level operation.
  • —: not applicable to that feature.

The columns are deliberately independent:

  • Read means expose the content as a supported model, not merely retain bytes.
  • Write means serialize supported content; raw-payload passthrough is identified.
  • Edit means change the supported model and save it using public APIs. Replacing a complete image is different from a random-access or in-place file edit.
  • Preserve means retain the stated information through the relevant save path. It does not promise byte-identical files, preservation of arbitrary unknown content in every editing path, or lossless conversion between formats.
  • Evaluate means interpret the feature's semantics, such as physical sample scaling, integrity verification or a coordinate transform. Keeping a WCS header does not mean its transform can be evaluated.

Classes of features: Format covers native format structures/semantics; Convention covers a particular FITS/application convention; API covers access, editing or workflow behaviour; Processing covers image/astronomy work above file-format I/O. A missing processing operation is not missing format decoding.

FITS containers, pixels and headers

Primary image and IMAGE extension HDUs; multiple HDUs — Format Yes Yes Yes Yes Yes Public models support complete image replacement. Geometry and payload bytes are retained; records/cards are reserialized. Models, tests.

Random groups / radio UVFITS — Format/convention No No No No No Some enum/length recognition exists, but there is no supported random-groups document/data model. Reader, document validation. Planned AV-028.

FITS tables

Feature / class Read Write Edit Preserve Evaluate Scope and evidence
ASCII tables — Format Yes Partial Partial Partial Partial Decoded rows are read-only. Existing tables can be saved from retained raw storage; there is no typed table builder or serialization of edited decoded rows. Unscaled I fields retain Int64; scaled numeric fields use double. Reader, tests.
Binary scalar/fixed-array fields, bit/complex/logical fields — Format Partial Partial Partial Partial Partial Supported type codes decode; typed vectors are exposed. Logical missing-value handling is incomplete, and scaled integer values may lose precision through double. Writing/editing requires retained or manually rebuilt raw storage. Reader, tests.
P/Q variable-length heap arrays — Format Yes Partial Partial Partial Yes Zero/one descriptor repetition, empty arrays, bounds and decoded-element budgets are checked. No public typed heap builder. Reader, boundary tests.
Table TSCAL/TZERO/TNULL and units — Format Partial Partial Partial Partial Partial Metadata and supported null/scaling semantics are decoded. ASCII null text is recognized before conversion. Exact unsigned-64 scaled columns and logical null semantics need further work. Column model, tests.
Multidimensional columns / TDIM — Format Partial Partial No Partial No The keyword can be read/preserved through the header, but decoded array fields remain flat and TDIM shape semantics are not evaluated. Keyword catalog, table parser. Planned AV-017.
Compressed tables — Format/convention No No No Partial No No decompression/editing API; opaque supported storage may be retained as a generic table. Table dispatch. Planned AV-028.

XISF containers, samples and metadata

Feature / class Read Write Edit Preserve Evaluate Scope and evidence
Monolithic XISF; distributed XISH + indexed XISB — Format Yes Yes Yes Partial Yes Distributed output is two sequential files, not a transaction. Original sources may remain necessary for opaque blocks. Writer, container tests, path tests.
Attached, embedded and inline Base64/hex data; both byte orders — Format Yes Yes Yes Yes Yes Size limits apply before text decoding/allocation. Editing is through owned models, not arbitrary in-place updates. Blocks, storage tests, resource tests.
zlib, LZ4, LZ4HC, Zstandard; shuffle/subblocks/alignment — Format Yes Yes Yes Yes Yes Codecs process full blocks/subblocks; region access does not imply partial decompression. Reader, writer, codec matrix tests.
SHA-1, SHA-256/512, SHA3-256/512 block digests — Format Yes Yes — Partial Yes Digests verify serialized bytes before decompression. Lazy blocks are not verified merely by reading the XML header; re-encoding computes new digests. Blocks, SHA-3 tests.
UInt8/16/32/64, Float32/64, Complex32/64 image samples — Format Yes Yes Yes Yes Partial Exact matching-type sample paths exist. Complex values can be read, but the ordinary display/statistics/region helpers do not process complex images. Image, editable image, numeric tests.
Arbitrary axes; planar/interleaved channels; Gray/RGB/CIELab — Format Yes Yes Yes Yes Partial Storage is supported; built-in rendering, regions, statistics and histograms are mainly 2D real-image APIs. Utilities, layout tests.
Scalar properties, vectors/matrices, Boolean/String/TimePoint — Format Yes Yes Yes Yes Yes Typed and custom identifiers; case-sensitive property access. Known-field/property editing is distinct from preserving arbitrary unknown XML. Properties, type tests, catalog tests.
128-bit integer and binary128 real/complex property storage — Format Yes Yes Yes Yes Partial Precise storage/parsing/formatting is supported; these types are not a general quadruple-precision arithmetic or image-pixel engine. Types, tests.
XISF document/image tables, including array cells — Format Yes Yes Yes Partial Yes Editable fields/rows are supported. Unknown/unavailable cells may retain source-backed opaque representations. Table models, document editing, tests.
FITS keywords, ICC, thumbnail, CFA, RGB working space, display function, resolution and orientation — Format Yes Yes Yes Partial Partial Color/display transforms are implemented. CFA is metadata, not debayering; ICC data is retained, not a full ICC colour-management engine. Orientation affects previews, not automatically scientific storage. Models, renderer, tests.
Unknown extensions/types and unavailable optional objects — Format/API Partial Partial Partial Partial No Preserve through document-aware save paths without interpreting unsupported semantics. Rebuilding an editable image does not guarantee arbitrary unknown attributes survive. Editable document, preservation tests.
Detached XML signatures — Format Yes Partial Partial Partial Partial RSA signing and embedded-key integrity checks are implemented. An edit/layout change generally requires re-signing. Verification does not establish signer identity, certificate-chain trust or arbitrary XML-subset transform support. Signing, tests.
Header-relative/external resources and URL resolution — Format/API Partial Yes Partial Partial Partial Filesystem/network access follows explicit policies; network access is disabled by default. Custom resolvers are optional. HTTP acquisition/body reads honor NetworkTimeout; custom resolvers/streams must cooperate. See timeout tests. Options, blocks, policy tests.
Semantic and caller-supplied XSD validation — Format/API Yes — — — Partial Diagnostics and Validate(XmlSchemaSet) exist. The library does not ship an exhaustive certification oracle or imply that loading a header verifies every lazy payload. Validation, API, tests.

Coordinates and astronomical semantics

Feature / class Read Write Edit Preserve Evaluate Scope and evidence
FITS WCS keywords as header metadata — Format/convention Yes Yes Yes Yes Partial Reading/preserving CTYPE, distortion or alternate-WCS cards does not imply their transform is supported. Typed keys, metadata tests.
Degree-based RA/DEC TAN, CD or PC/CDELT — Format/convention Yes Yes Yes Yes Yes The convenience evaluator supports this axis order and its documented pole/default restrictions. Headers without both CTYPE values retain a legacy linear mode. WCS evaluator, tests.
FITS SIP/TPV, other projections, alternate/axis-swapped/non-degree WCS, spectral/time/table WCS — Convention/Format Yes Yes Yes Yes No Metadata remains accessible; unsupported explicit transforms are rejected rather than approximated. Coordinate-frame transformations are also not implemented. WCS gate, rejection tests. Planned AV-019–AV-022.
Native XISF Revision 1 astrometry — Format Yes Yes Partial Partial Yes Seven projections, spherical rotation, both stored projective directions, spline distortion layers and fallback are implemented. Known properties can be edited, but the library does not fit/solve the models. Evaluator, projection/distortion tests.
Future/unknown native astrometric revisions — Format/API Partial Partial No Partial No Retain unavailable representations through preserving save paths; do not claim evaluation of unknown revisions. Evaluator, preservation tests.
Common object/instrument/observation metadata — API Yes Yes Yes Partial Partial A normalized view exposes selected known fields; it is not a complete physical-unit/time-scale conversion system. Metadata, quote/case tests.

Evidence and interpretation limits

Source/test links identify the implementation and representative regressions, not exhaustive proof of all combinations. Existing generated-byte, round-trip, malformed input and cross-platform tests are complemented by Phase 1 independent-reader fixtures; the fixture provenance/manifests must distinguish independently produced files from files produced by AstroView for reverse-direction checks.

The optional local corpus test checks user photographs outside Git. Eleven FITS photographs passed the previous review. The local XISF test now checks independent pixel hashes for 73 files/79 images, metadata/attachment preservation for complete files and two known missing-thumbnail failures. Sixty small committed independent fixtures run on all three CI platforms. Real native XISF distortion solutions still need independent reference evidence before broad interoperability claims are made. Keep external fixture redistribution licenses and source hashes alongside the fixtures.

Use the roadmap to select the next gap, and testing for commands and the distinction between portable fixtures and local photographs. Format references: FITS 4.0, FITS WCS, FITS tile compression, XISF specification.

Phase 1 evidence: independent corpus and limitations, offline fixture tests.

The desktop workspace exposes the currently implemented capabilities through a feature guide and interactive tools. Its demonstration files are not independent producer fixtures. GUI integration also protects the optional absence of an ordered interval for complex samples: bounds validation regressions.
