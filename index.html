AstroView documentation

AstroView reads, inspects, validates and writes astronomical FITS and XISF images. Choose the documentation for the work you want to do. The published edition is at AstroView documentation.

The guides track the current source targeting 0.3.0. Phase 2 additions are marked as development features and are absent from the published 0.2.0 release. Features still on the roadmap are identified explicitly. Being able to preserve metadata does not always mean that AstroView can evaluate or edit its scientific meaning: consult the support matrix for the detailed contract.

Developer route

Start with installation, then learn the document and pixel models. Choose the XISF or FITS guide for your input format. Conversion, integrity and performance explain decisions that affect real applications. The examples are compiled and executed during documentation CI.

Desktop route

Install AstroView and follow the reference-scene walkthrough. Then use the chapters for image viewing, metadata, analysis, tables, coordinates, integrity and export.

Read and search

These guides are Markdown files and can be read directly in the repository. The generated HTML edition adds search, navigation and the complete Core API reference. Run eng/Build-Documentation.ps1 -Serve from PowerShell, then open http://localhost:8080. See building documentation for prerequisites, downloadable CI output and maintenance instructions.

For release downloads, use the repository's GitHub Releases. The desktop application and Core library are supplied separately; there may be no published release yet while the project is in development.
