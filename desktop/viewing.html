AstroView

Viewing images

The Image workspace presents a display rendering of the selected scientific image. The dimensions/sample summary above it describes the underlying data, not an 8-bit conversion of that data.

Navigate the image

Control Result
Fit / Ctrl+0 Fits the preview in the available viewport
1:1 / Ctrl+1 Sets actual-size viewing
Mouse wheel Zooms the view
Left drag Pans the image
Double-click Fits the image again
Click Selects a pixel and updates the position readout
Selection crosshair Shows/hides the selection marker

Pixel positions shown by the workspace are zero-based image positions. Source orientation is accounted for when mapping a displayed selection. Panning and zooming do not crop, resize or rotate the stored scientific image.

Choose a display mode

In the right-hand DISPLAY panel, choose a mode and click Apply display. Scroll the panel if lower controls are outside the window.

Mode Use it when
Auto stretch You want faint astronomical structure to be visible without manually scaling source samples
Linear You want a preview based on linear normalization, for example to inspect an integer gradient
Stored display function The file contains display settings you want AstroView to use

Target background controls the automatic stretch's background target. The application starts at 0.22. Shadows clipping (σ) adjusts the shadow clipping parameter; the initial value is -2.8. These are display controls, not changes to black-level calibration in the original data.

With Link colour channels selected, the stretch links channels rather than independently stretching each channel. Try linked channels first for an RGB image; independent channel stretches can change apparent color balance. Compare the result visually and use Analyze for the actual sample measurements.

A file may lack a meaningful stored display function. Do not interpret that as missing pixel data; try Auto stretch or Linear. Different display modes can make the same scientific samples appear quite different.

Observation summary

The OBSERVATION panel summarizes recognized object, telescope, exposure and filter metadata. Missing fields are left out; the app does not infer a missing exposure or telescope from the image appearance. Use Inspect for individual metadata values and scope.

FITS color-axis interpretation

A third FITS axis is preserved as a scientific axis by default. If your file is known to store RGB/RGBA planes in that axis:

  1. Select the FITS image.
  2. Scroll to FITS AXES.
  3. Select Interpret 3rd axis as RGB/RGBA.
  4. Click Apply axis interpretation.

Use this only when the third axis really represents color. A cube with three spectral planes is not automatically an RGB photograph. This choice also informs subsequent format conversion; review it before exporting.

Export the visible rendering

Click Export preview as PNG… and choose a new filename. The PNG represents the rendered preview, including the chosen display transformation and supported orientation/color interpretation. It does not retain scientific sample precision, the whole FITS/XISF document or its catalog metadata. Use Export for a scientific document copy.

When there is no preview

Complex-valued images and general scientific cubes remain available to inspection, but do not have a general magnitude/phase or cube-plane bitmap renderer in the current implementation. Use Analyze → Exact stored samples and Inspect. A table HDU or empty primary HDU can also legitimately have no preview. See troubleshooting before changing reader limits.
