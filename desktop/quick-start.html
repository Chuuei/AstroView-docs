AstroView

First steps with the reference scene

This walkthrough needs no files or internet connection. It introduces viewing, measurement, metadata and output before you work on your own observations.

1. Explore the four reference images

On a normal empty launch, AstroView creates its reference scene. If you opened files at launch instead, click Reference scene to add a reference document. Select Reference scene.xisf in DOCUMENTS, then Emission nebula under IMAGES & HDUs.

The scene includes:

Item Purpose
Emission nebula Float32 RGB preview, observation metadata, native astrometry and a star catalog
UInt16 gradient Integer samples and histogram bounds
Scientific cube Additional scientific axes without a general cube-plane preview
Complex wave Complex-valued samples available in the sample inspector

The nebula is generated demonstration data. It is not a real exposure or an independent test of another application's format implementation.

2. Change the view

  1. Select the Image workspace.
  2. Click Fit, then use the mouse wheel to zoom in.
  3. Drag the image to pan, and double-click to fit it again.
  4. Change the display mode from Auto stretch to Linear.
  5. Click Apply display, compare the preview, then restore Auto stretch.

A darker linear preview is expected for many faint images. The scientific samples remain unchanged throughout this exercise. See viewing for linked channels, shadow clipping and PNG output.

3. Run an analysis

  1. Select Analyze with the emission nebula still selected.
  2. Choose channel 0, bounds 0 to 1, and 256 bins.
  3. Leave the statistics sample limit at 250000 and click Run analysis.
  4. Read the histogram totals and the three channel-statistics rows.

The histogram counts every sample in its chosen channel. Statistics can be sampled, so the finite counts in the statistics table need not equal the histogram count. To try integer bounds, select UInt16 gradient, set histogram bounds to 0 and 65535, then run analysis again.

4. Add a note

  1. Return to Emission nebula and choose Inspect → Fields.
  2. In the metadata editor, select Image property.
  3. Enter key AstroView:Note, type String, and value First inspection.
  4. Click Apply metadata edit.
  5. Search for AstroView:Note in the fields list and confirm its value/scope.

The note is in the open document's memory. It has not been written to disk.

5. Browse the catalog and coordinates

Open Tables and select the reference-star catalog. Notice that large integer identifiers retain exact text. Then open Coordinates, enter image column 512 and row 384, and click Calculate sky coordinates. Click Calculate image coordinates to transform the resulting RA/Dec back.

AstroView uses zero-based image positions and degrees for sky angles in this workspace. See coordinates before entering RA in another unit.

6. Validate and save a copy

  1. Open Integrity and click Validate document.
  2. Review the diagnostic list, including payload-decoding information.
  3. Open Export and select Keep native document.
  4. Click Export document… and save as reference-reviewed.xisf in a new location.
  5. Reopen that file and find your AstroView:Note in Inspect.

This confirms that the in-memory note was saved. To share a picture rather than a scientific document, use Image → Export preview as PNG… instead.

You can now open your own documents and follow the same inspect → validate → export workflow.
