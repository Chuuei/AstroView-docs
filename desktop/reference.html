Numeric spin controls can follow the operating system's decimal separator. That does not change the invariant syntax required by metadata text and JSON.

Interactive limits

Tool Limit/default

Histogram 256 bins initially; 8–4,096 bins

These are interactive application limits, not an exhaustive statement of Core's format limits. File readers also enforce independent byte, XML, dimension, decompression and table budgets.

Current capability boundaries

AstroView exposes the capabilities implemented by Core. Current limitations include general complex magnitude/phase previews, scientific cube-plane viewing, native FITS table editing, compressed/tiled FITS image decoding, broader FITS WCS/distortion evaluation, debayering, full ICC processing and general streaming or memory-mapped image processing.

The seven projections in the synthetic/native-XISF calculator do not imply seven implemented FITS WCS projection families. Inspectable CFA/ICC metadata does not imply that those processing operations are available. A feature listed as planned in Feature lab cannot be enabled through a different export setting.

Use the support matrix for read/write/edit/preserve/evaluate details and the roadmap for planned work. The Core developer guide explains API integration separately from this user manual.
